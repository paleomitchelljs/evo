Instructor tool — runs entirely in the browser, nothing is sent anywhere. Paste a student code, type the student's name, and confirm the adjective + animal match. Use the roster generator to pre-compute the expected passcode for every student in a class for a given module.

Verify a single submission

Paste the code. The embedded name token is hashed and compared to the embedded passcode. If the student typed a different spelling than the roster, you can override the name to test alternative spellings.

Roster — expected passcodes for a class

Paste one student name per line, set a module ID, and get the passcode each student's code should start with for that module. Names are normalized (lowercased, whitespace collapsed) before hashing.
