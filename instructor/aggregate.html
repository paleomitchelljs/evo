Class score aggregator

Instructor tool — runs entirely in the browser; the roster lives in this browser's local storage and persists across sessions. Paste student codes (one per line) as they email them in and press Add to roster; the name × lesson matrix updates and grows. Each cell is correct/total · time on task; hover it for the wall clock and the control-move count. Below the matrix, the item analysis turns the same codes around and reads the lessons instead of the students. A code that won't decode (wrong salt, edited, or not a v3 code) is listed separately and never silently scored.

Item analysis — how the lesson did

The matrix above reads the students. This reads the lessons. Each bar is the fraction of the class that got that one question right. A checkpoint everybody clears is doing its job; one nobody clears is either the hard-won move the lesson exists to teach, or a question that does not say what it means — and which of those it is usually becomes obvious once you open the lesson and look at the item next to the number.

Add some codes and this fills in.
