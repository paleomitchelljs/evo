Score code verifier

Instructor tool — runs entirely in the browser, nothing is sent anywhere. Paste one student code and the salt you set in that module's Score.init. The code is opaque to students; this tool decodes the name, the per-question right/wrong bits, the elapsed working time, and the per-stage activity counts, and confirms the tamper tag. For a whole class at once, use aggregate.html.

What's in the code

The cleartext prefix moduleNvVERSION tells you which lesson and scoring revision the code is for. Everything after the first . is the student's name, their right/wrong bits, the elapsed seconds, and the per-stage manipulation counts, XOR-encrypted with a keystream derived from your salt and base64url-encoded, followed by a 6-hex tamper tag. A VALID verdict means the tag matches — the code decoded cleanly and was not edited. A salt mismatch verdict means the salt you typed is not the one the module used.
