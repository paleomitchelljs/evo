Score code verifier

Instructor tool — runs entirely in the browser, nothing is sent anywhere. Paste one student code; the salt is pre-filled from score.js and only needs changing if that module set its own. The code is opaque to students; this tool decodes the name, which questions they got right, how long they actually worked, and how many times they moved a control on each stage, and confirms the tamper tag. For a whole class at once use aggregate.html, or python3 scripts/decode_codes.py -f codes.txt --items from the terminal.

What's in the code

The cleartext prefix moduleNvVERSION tells you which lesson and scoring revision the code is for. Everything after the first . is the student's name, their right/wrong bits, two clocks, and the per-stage manipulation counts, XOR-encrypted with a keystream derived from your salt and base64url-encoded, followed by a 6-hex tamper tag. A VALID verdict means the tag matches — the code decoded cleanly and was not edited. A salt mismatch verdict means the salt you typed is not the one the module used.

The two clocks. Wall clock runs from the moment the student confirms their name to the moment they submit, so a tab left open over dinner reads as hours. Attention adds up only the intervals between consecutive signs of life — clicks, keys, scrolling, returning to the tab — discarding any pause longer than two minutes. Neither is proof of thought: attention still counts a student who idly wiggles a slider, and the per-stage move counts are the cross-check. Codes issued before this was added show attention as not measured.
