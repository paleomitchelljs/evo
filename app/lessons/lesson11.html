A

Locked — confirm your name above to begin.

Being heterozygous at a locus means having two distinct genetic ancestors for that locus. Inbreeding reduces the number of ancestors you have, and so makes having two distinct ancestors for a given locus less likely.

  • Four hundred individuals, one locus, two alleles. Each individual is two halves, one per copy.
  • Nothing dies and nothing is selected. The only control is who pairs with whom.
  • F: how far the heterozygote count falls short of what random pairing would give.

R code

# 400 individuals, two copies each, at one locusp <- 0.5          # how common the purple allele isf <- 0            # how often a partner is a relativeHo <- mean(a != b)   # heterozygotes, countedp  <- mean(c(a, b))   # the frequency they implyHe <- 2 * p * (1 - p)  # what random pairing would giveF  <- 1 - Ho / He

C

You inherit alleles, not genotypes. A genotype is a pairing, made fresh every generation and taken apart again when that individual breeds.

  • Click a founder in the top row, then pick its two alleles. Two of the same colour is a homozygote.
  • Drop it down: every offspring takes one copy from each parent, picked by a coin.
  • The slider rebuilds the tree with more or fewer matings between relatives.
  • Bottom plot: how common each founder allele is in each generation, and F in each generation. Faint lines are single drops.

D

Solve Stage C to unlock this section.
  • The plot: F over forty generations. The red band is the target.
  • Two controls: how many individuals breed, and how often a partner is a relative.
  • Every run stays on the plot, faint, until the next target.
  • Tick practice for a run that does not count.

R code

# how many breed, and how often a partner is a relative, for 40 generationsn    <- 1000   # breeders, in pairsf    <- 0.00   # how often a partner is a relativeloci <- 80g   <- array(rbinom(2*n*loci, 1, 0.5), c(2, loci, n))sib <- rep(NA, n)H   <- mean(g[1,,] != g[2,,])   # heterozygotes, countedfor (t in 1:40) {  kid <- g; ksib <- sib  for (pr in 1:(n/2)) {    m <- sample(n, 1)    d <- if (runif(1) < f && !is.na(sib[m])) sib[m] else sample(setdiff(1:n, m), 1)    for (k in c(2*pr - 1, 2*pr)) {   # two offspring a pair      kid[1,,k] <- g[cbind(sample(2, loci, TRUE), 1:loci, m)]      kid[2,,k] <- g[cbind(sample(2, loci, TRUE), 1:loci, d)]    }    ksib[2*pr - 1] <- 2*pr; ksib[2*pr] <- 2*pr - 1  }  g <- kid; sib <- ksib  H <- c(H, mean(g[1,,] != g[2,,]))}F <- 1 - H / H[1]
