  • 300 parents. Across: the trait. Up: how many offspring each leaves. Colour: which of three groups it belongs to — it does nothing yet.
  • Drag on the top plot to tilt the line: how many offspring a parent leaves, on average, for its trait.

B

Solve Stage A to unlock this section.
  • Each round is a new population of 2000. The trait varies by the same amount in every one; how much of that variation is inherited you are not told.
  • The slope is Stage A's line. Go runs one generation: parents breed in pairs, as often as the line says. A child gets the average of its parents' inherited values, give or take; the rest of the trait it does not inherit.
  • Top plot: every run adds a point — how far the mean of the parents who bred moved (Stage A's shift), across, and how far the offspring's mean moved, up. One colour per population. Practice runs add points too.
  • Bottom plot: one generation — the parents, the parents counted once per child, and the children.
  • Tick practice for a run that does not count.

R code

# one generation of selection on a partly inherited traitN  <- 2000; h2 <- ?   # inherited sharea  <- rnorm(N, 0, sqrt(h2))         # inherited valuez  <- 10 + a + rnorm(N, 0, sqrt(1 - h2))   # the traitslope <- 0.00w  <- pmax(0, 2 + slope * (z - mean(z)))p1 <- sample(N, N, TRUE, w); p2 <- sample(N, N, TRUE, w)ao <- (a[p1] + a[p2]) / 2 + rnorm(N, 0, sqrt(h2 / 2))zo <- 10 + ao + rnorm(N, 0, sqrt(1 - h2))S <- mean(z[c(p1, p2)]) - mean(z)   # the parents who bred movedR <- mean(zo) - mean(z)              # the offspring movedR / S

C

Solve Stage B to unlock this section.
  • Each round is a new population of 200 plants. Two traits, flower size and stem height, and one count, seeds set.
  • The diagram is the controls. Each trait's arrow is how many seeds one unit of that trait adds; blue pushes seeds up, brown pulls them down. The other causes arrow is how far everything else scatters the seeds.
  • Top plots: seeds against each trait, with the diagram's line and the spread the diagram expects in that picture.
  • Bottom plot: what is left of the seeds once the diagram's arrows are taken out. In a round it waits for Go; with practice ticked it moves as you set the arrows.
  • Go grows seeds from your diagram on the same plants and lays them over the real ones.

D

Solve Stage C to unlock this section.
  • Each round is a new population of 300 plants, each carrying 0, 1 or 2 copies of an allele. The allele can make flowers bigger and stems taller: those two arrows are dealt, drawn on the diagram, and not yours to set.
  • You set the arrows into seeds set: from the allele itself, from flower size, from stem height, and from other causes.
  • Top plots: seeds against each of the three, with the line and band your whole diagram expects in that picture. When the allele ties two traits together, a trait's picture can tilt with its own arrow at zero.
  • Bottom plot: what is left over once your arrows are taken out. In a round it waits for Go; with practice ticked it moves as you set the arrows.
