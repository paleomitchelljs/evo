A

Locked — confirm your name above to begin.
  • A meadow with room for 200 flowers. Color runs from dark orange (0) to dark purple (10). Its color is passed down through 100 genes, each with a purple and an orange allele: every purple copy adds a little, every orange copy takes a little away. A little of the color is not passed down.
  • Three visitors, set on the map in Controls: hummingbirds choose colors from 0 up to their edge, bees from their edge up to 10, butterflies most around one color, less and less either side. Drag a handle to move an edge, the butterflies' favorite, or how far either side they go; click the slots on the left to set how many come.
  • A visit sets a seed. Its pollen comes from a flower the same kind of visitor called on. One seed in 16 grows, up to the 200 the meadow has room for. No visits, no seeds.
  • Predict: the seeds a flower of each color can expect, with every flower stacked on it; the start stays in grey. Go plays 20 generations.
  • Under the meadow: how many flowers of each color, generation by generation, and what moved the average color each time: cov(w, z), who reproduced; E(wΔz), transmission bias; Δz, the change. w is a flower's offspring ÷ the meadow's average.
  • Play some runs first; Start the targets when you are ready. Tick practice for a run that does not count.

R code

# a meadow with room for 200: color 0 (dark orange) to 10 (dark purple)L <- 100                                    # genes, each with a purple and an orange alleleg <- matrix(rbinom(200 * 2 * L, 1, 0.5), 200)   # 1 = a purple copycolor <- function(g) pmin(10, pmax(0, 5 + 0.08 * (2 * rowSums(g) - 2 * L) + rnorm(nrow(g), 0, 0.5)))ramp <- function(d) 0.1 + 0.9 * pmin(1, pmax(0, d / 2))   # chosen 1, fading to 0.1 over 2 colorsnH <- 5; tH <- 10                     # hummingbirds: colors 0 to tHnB <- 5; tB <- 0                     # bees: colors tB to 10nF <- 0; mu <- 5; sp <- 1.5            # butterflies: around mu, give or take spfor (gen in 1:20) {  z <- color(g); n <- nrow(g)  v <- cbind(rpois(n, 8 * nH * ramp(tH - z + 2)),        # visits, by kind             rpois(n, 8 * nB * ramp(z - tB + 2)),             rpois(n, 8 * nF * (0.1 + 0.9 * exp(-(z - mu)^2 / (2 * sp^2)))))  kids <- min(200, rbinom(1, sum(v), 1/16))   # one seed in 16 grows; room for 200  if (kids == 0) break                        # no seedlings: the meadow is gone  s   <- sample(length(v), kids, TRUE, v)     # a seed: which flower, which kind set it  mom <- (s - 1) %% n + 1; kind <- (s - 1) %/% n + 1  dad <- sapply(kind, function(k) sample(n, 1, prob = v[, k]))   # pollen from that kind's calls  kid <- matrix(0, kids, 2 * L)  for (l in 1:L) {                            # one copy of each gene from each parent    kid[, 2*l - 1] <- g[cbind(mom, 2*l - rbinom(kids, 1, 0.5))]    kid[, 2*l]     <- g[cbind(dad, 2*l - rbinom(kids, 1, 0.5))] }  zk <- color(kid)  w  <- tabulate(c(mom, dad), n)              # offspring each flower left  zs <- sapply(1:n, function(i) sum(zk[mom == i]) + sum(zk[dad == i]))  sel <- mean((w - mean(w)) * (z - mean(z))) / mean(w)     # cov(w, z) / w-bar  off <- mean(zs - w * z) / mean(w)                        # E(w dz) / w-bar  print(c(kids, sel, off, sel + off, mean(zk) - mean(z)))   # the last two agree  g <- kid}

Solve Stage A to unlock this section.
  • 300 parents. Across: the trait. Up: how many offspring each leaves. Colour: which of three groups it belongs to — it does nothing yet.
  • Drag on the top plot to tilt the line: how many offspring a parent leaves, on average, for its trait.
  • Each dot draws a rectangle to the middle: blue where trait and offspring are both above or both below average, red where they disagree. The covariance is the average rectangle.
  • Bottom plot: the trait in the parents, and in their offspring. Every offspring copies its parent's trait — for now.
  • Go draws how many offspring each parent actually leaves. Tick practice to watch the offspring move as you drag.

C

Solve Stage B to unlock this section.
  • Each round is a new population of 2000. The trait varies by the same amount in every one; how much of that variation is inherited you are not told.
  • The slope is Stage B's line. Go runs one generation: parents breed in pairs, as often as the line says. A child gets the average of its parents' inherited values, give or take; the rest of the trait it does not inherit.
  • Top plot: every run adds a point — how far the mean of the parents who bred moved (Stage B's shift), across, and how far the offspring's mean moved, up. One colour per population. Practice runs add points too.
  • Bottom plot: one generation — the parents, the parents counted once per child, and the children.

F

Solve Stage E to unlock this section.
  • Each round is 2000 seedlings. Flower size and stem height are drawn separately: across all the seedlings, one tells you nothing about the other.
  • A drought kills a share of them. Which ones live is set by the diagram: flower size and stem height each count toward surviving, by the dealt arrows, and luck adds the rest.
  • You set how hard the drought is. Go runs it. The survivors are the plants a field biologist would find and measure.
  • Top plot: stem height against flower size for every seedling, survivors filled and the dead hollow, with the line through the survivors.
  • Bottom plot: every run adds a point: the share the drought killed, and the slope it left among the survivors.
