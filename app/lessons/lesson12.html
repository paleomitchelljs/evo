Alleles code for proteins. What that protein does produces the phenotype. If a protein makes red pigment, you're adding red paint to a flower. A broken pigment allele adds nothing. Add nothing to nothing, you get nothing — white flower.

I have a field with hummingbirds and bees. Hummingbirds like red flowers, bees like white. More hummingbirds than bees, so red has higher relative fitness. Which one likes pink?

  • 36 flowers, 12 of each genotype. The two squares under a flower are its two copies, red or white.
  • red from one copy: how red a flower with one red copy is, from 0 (white) to 1 (as red as two copies).
  • Hummingbirds take flowers at least as red as their edge; bees, flowers at most as red as theirs. Colours they do not take get a few visits. Drag pink or either edge on the middle plot.
  • Go plays a season: 300 visits from each visitor, one seed a visit.
  • The bars: seeds per flower, against white. s is how far red sits above white; h is where pink sits on the ruler from white (0) to red (1).
  • Tick practice for a run that does not count.

R code

Pine trees — do they want their seeds to be eaten? No. The trees that made pinecone seeds that were easy to eat — what happened to them? They died. The trees that survived are the ones that had pinecone seeds that weren't easy to eat. That's more or less all selection is doing — the ones that aren't good enough to make more of themselves don't make more of themselves.

  • Individuals, one locus, two alleles. Each individual is two halves, one per copy.
  • The bars, as in Stage A: how many offspring each genotype leaves, against the yellow homozygote. s moves the purple homozygote; h moves the heterozygote, from below both to above both.
  • F is held where you set it, every generation.
  • Bottom plot: how common purple is. A run has to pass through every red window.
  • Tick practice for a run that does not count.

Solve Stage B to unlock this section.
  • Four alleles at one locus, each starting in a quarter of the copies. Each has its own h and s.
  • The grid: every genotype's fitness. A homozygote is 1 + s; a heterozygote adds each allele's h × s.
  • Go runs 200 populations until one allele is left, or 600 generations. Each line is the allele that won, in its colour; dots mark when.
  • The bars: how often each allele won. Match the red outlines.
  • All neutral sets every s to 0.
  • Tick practice for a run that does not count.

R code

# four alleles, each with its own h and sh <- c(0.5, 0.5, 0.5, 0.5)s <- c(0, 0, 0, 0)N <- 100; F <- 0.00w <- outer(1:4, 1:4, function(i, j)       ifelse(i == j, 1 + s[i], 1 + h[i] * s[i] + h[j] * s[j]))winner <- replicate(200, {  g <- matrix(sample(rep_len(1:4, 2 * N)), 2)  t <- 0  while (length(unique(c(g))) > 1 && t < 600) {    fit <- w[cbind(g[1, ], g[2, ])]    p1 <- sample(N, N, TRUE, fit)    p2 <- ifelse(runif(N) < 2 * F / (1 + F), p1, sample(N, N, TRUE, fit))    g  <- rbind(g[cbind(sample(2, N, TRUE), p1)], g[cbind(sample(2, N, TRUE), p2)])    t  <- t + 1  }  if (length(unique(c(g))) == 1) g[1] else 0   # 0 = still mixed})table(factor(winner, 0:4)) / 200

D

Solve Stage C to unlock this section.
  • 50 populations. Every individual starts on the low peak: no + copies at either of two loci.
  • The trait is how many + copies an individual carries, 0 to 4. The high peak needs all four; anything between sits in the valley.
  • New + copies arise by mutation, 1 copy in 1000 each generation. Selection pushes every one of them back down.
  • The balls are the populations. One has reached the high peak when its average is 3.5. Each run lasts 1500 generations.
  • Tick practice for a run that does not count.

R code

E

Solve Stage D to unlock this section.

Selection is the only thing that can make things consistently better — but it's also pretty weak, so it doesn't work that well. And by "better," it doesn't mean better in some objective sense. Just die less or have more kids.

How many children individuals in your population have on average — that's what fitness is.

  • Stage B's population: individuals, one locus, h and s, F held where you set it.
  • Average fitness: the offspring an individual leaves, against the yellow homozygote, averaged over the whole population each generation.
  • Top plot: average fitness against how common purple is. The line is where a population with that much purple sits; dashed, with F where it is held. The ball is this population.
  • Bottom plot: average fitness by generation, through the red windows. The dotted line is the fittest genotype.
  • Tick practice for a run that does not count.

Selection is not a forward-thinking process. It's literally each generation: what makes more of itself? The lower peak is just as much a fixed point as the higher peak. Selection cannot see across the valley.
