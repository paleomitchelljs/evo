R code — FSJ Nₑ

fsj <- read.csv("data/clean/fsj_allele_freq.csv")H <- tapply(2*fsj$p*(1-fsj$p), fsj$year, mean)yrs <- as.numeric(names(H))Ne_grid <- seq(10, 5000, 10)ssr <- sapply(Ne_grid, function(N) {  Hp <- H[1] * (1 - 1/(2*N))^(yrs - yrs[1])  sum((H - Hp)^2)})

One sentence to carry forward

The effective population size is almost never the census size. It is the size of the gene pool you can actually draw from — and that pool is what determines how fast drift acts. Drift is always stronger than it looks.— composite: 202_lec10_06 + 461_lec09_07
